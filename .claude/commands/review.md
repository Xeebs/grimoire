Review a staged skill against the Grimoire quality bar before publishing. Usage: /project:review {skill-path}

Steps:
1. Read the skill's SKILL.md, README.md, and both test scenarios
2. Check novelty — search GitHub and public prompt libraries for similar skills
3. Verify industry accuracy — correct terminology, role titles, document types
4. Confirm the portable README.md is self-contained and usable without Claude Code
5. Re-run test scenarios and verify output criteria are met
6. Output a pass/fail verdict with specific feedback on any failures
